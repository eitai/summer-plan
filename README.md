# תוכנית הקיץ

מתכנן חופש, 8 באוגוסט – 1 בספטמבר 2026. קובץ אחד, בלי build, בלי dependencies.

## עיצוב

הפלטה והפונט נלקחו מ-**Light Studio** (`Photographer-Dashboard`, ערכת `violet`
ב-`frontend/src/index.css`) — סגול `#7c3aed` על לבן, גבולות `#e4def2`, רקע רך
`#f5f3fb`, טקסט `#111111` ומשני `#5c5c66`, פונט **Heebo**, ו-`radius: 0`
(בלי פינות מעוגלות). אם הפלטה שם משתנה, זה המקור לעדכן ממנו.

## סנכרון בין מכשירים

כל הלוח הוא מסמך JSON יחיד, בשורה אחת (`id = 1`) בטבלת `plan` ב-Supabase.
אין ORM ואין SDK — שתי קריאות `fetch` ל-REST API.

### הקמה (פעם אחת)

1. ב-[supabase.com](https://supabase.com) → פרויקט (חדש או קיים) → **SQL Editor** → הרץ:

   ```sql
   create table plan (id int primary key, doc jsonb, updated_at timestamptz default now());
   alter table plan enable row level security;
   create policy "open" on plan for all using (true) with check (true);
   ```

2. **Project Settings → API** → העתק את `Project URL` ואת מפתח ה-`anon public`.

### חיבור

הכתובת והמפתח הפומבי מקובעים ב-`CONFIG` בראש ה-`<script>`, כך שכל מכשיר
שנכנס לאתר מסונכרן מיד בלי להזין כלום.

**המשמעות:** המפתח מוגש לכל מי שנכנס לאתר, וה-policy פתוחה — כלומר כל מי
שמגיע לכתובת יכול לקרוא, לערוך ולמחוק. הדף מסומן `noindex` כדי שלא יתגלה
דרך מנועי חיפוש, אבל זו הסתרה ולא הגנה. מספיק ללוח משפחתי, לא למידע רגיש.

ריקון `CONFIG` חזרה ל-`{url:"",key:""}` מכבה את הסנכרון והאפליקציה עוברת
לשמירה מקומית בלבד. `sbUrl()`/`sbKey()` קוראים קודם מ-localStorage
(`sp-url`/`sp-key`), כך שאפשר להזין ערכים פר-מכשיר מה-console אם אי פעם
תרצה סנכרון בלי להחזיק את המפתח בריפו.

## איך זה עובד

- **מעל 1251px זה מסך אחד** — היומן ועורך היום זה לצד זה, ולחיצה על יום מחליפה
  את הצד בלי לעזוב את היומן. מתחת לזה חוזרים לשני מסכים עם המתג יומן/יום למעלה
  (שניהם חולקים את אותו `grid-area`, אחד מהם `hidden`).
- החודשים זורמים זה לצד זה כשיש רוחב (`auto-fit,minmax(300px,1fr)`).
- יום = רשימת אירועים. לכל אירוע שעת התחלה ואופציונלית שעת סיום, והרשימה
  מסתדרת לבד לפי שעת ההתחלה.
- מבנה הנתונים: `days["YYYY-MM-DD"] = [{t:"HH:MM", e:"HH:MM"|"", x:"מה עושים"}]`.
  אין רשת שעות קבועה ואין הגבלה על שני אירועים באותה שעה.
- `migrate()` מריץ בטעינה ומעלה כל מסמך ישן לגרסה 3: v1 שמר `{"HH:MM":"טקסט"}`
  לכל יום, v2 היה `[{t,x}]` בלי שעת סיום.
- לוח השנה מתחיל ב-8.8 ולא ב-1.8 — הריפוד מחושב מ-`getDay()` של היום הראשון
  בכל חודש בטווח, כך שכל תאריך נופל בעמודה הנכונה.
- שמירה מקומית מיידית תמיד; דחיפה ל-Supabase אחרי 0.7 שניות של שקט, ומשיכה כל 20 שניות
  ובכל חזרה לטאב. מנצח מי ששמר אחרון.
- **ייצוא לקובץ** = גיבוי JSON מלא. **ייבוא** מחזיר אותו.
