# תוכנית הקיץ

מתכנן יומי לפי שעות, 8 באוגוסט – 1 בספטמבר 2026. עיצוב בהשראת Adobe Lightroom Classic.
קובץ אחד, בלי build, בלי dependencies.

## סנכרון בין מכשירים

כל הלוח הוא מסמך JSON יחיד, בשורה אחת (`id = 1`) בטבלת `plan` ב-Supabase.
אין ORM ואין SDK — שתי קריאות `fetch` ל-REST API.

### הקמה (פעם אחת)

1. ב-[supabase.com](https://supabase.com) → פרויקט (חדש או קיים) → **SQL Editor** → הרץ:

   ```sql
   create table plan (id int primary key, doc jsonb, updated_at timestamptz default now());
   alter table plan enable row level security;
   create policy "open" on plan for all using (true) with check (true);
   ```

2. **Project Settings → API** → העתק את `Project URL` ואת מפתח ה-`anon public`.

### חיבור

הכתובת והמפתח הפומבי מקובעים ב-`CONFIG` בראש ה-`<script>`, כך שכל מכשיר
שנכנס לאתר מסונכרן מיד בלי להזין כלום.

**המשמעות:** המפתח מוגש לכל מי שנכנס לאתר, וה-policy פתוחה — כלומר כל מי
שמגיע לכתובת יכול לקרוא, לערוך ולמחוק. הדף מסומן `noindex` כדי שלא יתגלה
דרך מנועי חיפוש, אבל זו הסתרה ולא הגנה. מספיק ללוח משפחתי, לא למידע רגיש.

**לחלופין, פרטי:** מרוקנים את `CONFIG` חזרה ל-`{url:"",key:""}`, ואז מופיע
כפתור **חבר סנכרון** בפאנל ההגדרות — מדביקים כתובת ומפתח פעם אחת בכל מכשיר,
והם נשמרים ב-localStorage בלבד ולא בריפו.

## איך זה עובד

- **טווח שעות** (פאנל ימני) קובע אילו שעות מוצגות בכל יום. הוא רק תבנית תצוגה — לא מוחק כלום.
- כל שעה ניתנת לעריכה בלחיצה עליה (אפשר להקליד `07:30`), ו-**+ הוסף שעה** מוסיף שורה משלך.
- טקסט נשמר לפי שעה, כך ששינוי הטווח לא מאבד מה שכבר נכתב.
- שמירה מקומית מיידית תמיד; דחיפה ל-Supabase אחרי 0.7 שניות של שקט, ומשיכה כל 20 שניות
  ובכל חזרה לטאב. מנצח מי ששמר אחרון.
- **ייצוא לקובץ** = גיבוי JSON מלא. **ייבוא** מחזיר אותו.
