# תוכנית הקיץ

מתכנן יומי לפי שעות, 8 באוגוסט – 1 בספטמבר 2026. עיצוב בהשראת Adobe Lightroom Classic.
קובץ אחד, בלי build, בלי dependencies.

## סנכרון בין מכשירים

הנתונים הם קובץ JSON יחיד (`plan.json`) בתוך Gist פרטי ב-GitHub. אין DB ואין שרת.

**מזהה ה-Gist והטוקן לא נמצאים בקוד** — הם נשמרים ב-localStorage של כל מכשיר בנפרד,
כי הריפו הזה ציבורי. לכן צריך לחבר כל מכשיר פעם אחת.

### חיבור מכשיר

1. פעם אחת בלבד — צור טוקן ב-[github.com/settings/personal-access-tokens](https://github.com/settings/personal-access-tokens):
   **Generate new token** → תוקף לפי בחירתך → **Account permissions → Gists: Read and write**.
   (זו ההרשאה היחידה שצריך. GitHub לא מאפשר להצר טוקן ל-Gist בודד — ההרשאה חלה על כל
   ה-Gists שבחשבון, אז אל תשמור ב-Gists אחרים דברים רגישים.)
2. באתר → פאנל ההגדרות → **חבר סנכרון** → הדבק את מזהה ה-Gist ואת הטוקן.
3. חזור על שלב 2 בפלאפון (אותו מזהה, אותו טוקן).

**נתק את המכשיר הזה** מוחק את הטוקן מהמכשיר בלי לגעת בנתונים.

### אם הטוקן דולף

מבטלים אותו בעמוד הטוקנים ויוצרים חדש. שים לב ש-Gist פרטי (secret) הוא לא באמת פרטי:
מי שיודע את המזהה יכול לקרוא אותו גם בלי טוקן. לכן המזהה לא נמצא בריפו.

## איך זה עובד

- **טווח שעות** (פאנל ימני) קובע אילו שעות מוצגות בכל יום. הוא רק תבנית תצוגה — לא מוחק כלום.
- כל שעה ניתנת לעריכה בלחיצה עליה (אפשר להקליד `07:30`), ו-**+ הוסף שעה** מוסיף שורה משלך.
- טקסט נשמר לפי שעה, כך ששינוי הטווח לא מאבד מה שכבר נכתב.
- שמירה מקומית מיידית תמיד; דחיפה ל-Gist אחרי 0.7 שניות של שקט, ומשיכה כל 20 שניות
  ובכל חזרה לטאב. מנצח מי ששמר אחרון.
- **ייצוא לקובץ** = גיבוי JSON מלא. **ייבוא** מחזיר אותו.
